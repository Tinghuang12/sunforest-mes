## 查核方式（簡述）

- **研究**：19 位研究員多語言搜尋。
- **查核**：10 位查核員以「嘗試推翻」為前提，各自重新搜尋，逐條判定。
- **主控二次查核**：關鍵論點由主控再查一次。
- **撰寫與稽核**：每章只用已查核論點撰寫，再逐句稽核；最後做跨章一致性終審。

狀態圖例：✅ 已驗證　🟡 部分驗證　⚪ 無法驗證　❌ 已推翻

**限制**：本環境無法直接打開網頁，所有判定依據是搜尋結果摘要。對外文件引用前，重要數字請人工打開原文再核對一次。
