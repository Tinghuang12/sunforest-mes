# 集團上市計劃（2026 年第 4 季至 2031 年上櫃）

**對象**：黃悟庭社長
**日期**：2026-10-01
**依據**：交接包 1.1、1.5 的【定案】（5 年內上市；主體是集團控股，不是設備公司單獨上市）；研究第 6、9 章；櫃買中心規定的獨立查核（附錄一，編號 IP-1 至 IP-10）；資金試算（附錄二）；上市前置時間的獨立查核（附錄三，編號 IL-1 至 IL-8）；反向驗證（PDF 11）

> **讀法**
>
> - **目標照【定案】**：2026Q4–2027H1 階段 0 → 2027 重組 → 2028 第一個查核年度 → 2029 公開發行、Pre-IPO → 2030 興櫃 → 2031 上櫃。本計劃把每一年要做的事、要達到的條件、會讓時程後延的觸發點排出來。
> - **上市的是集團**：櫃買中心看的是上市主體的合併財報。New Tech 在這份計劃裡的角色有兩個：不能讓集團帳出現累積虧損；可以當成長故事的一部分。
> - **第一年**（2026-10 至 2027-09）的細節在《New Tech 第一年活動計劃表》，兩份日期對齊。
> - **標記**：【定案】＝交接包已決定；【估算】附算式；【推論】＝判斷，不是查核過的事實；【提案】＝研究或紅隊建議，待裁決；【未決】＝要社長或外部回答。✅🟡⚪❌ 是查核狀態，方括號編號可在附錄查到來源：IP-x 在附錄一、IL-x 在附錄三。
> - **「財務長組」**：指第 9 章紅隊第二輪的「集團財務長＋家族股東」報告全文（PDF 08 附錄 B），條號照原文。
> - **規定以送件時的最新條文為準**：引用的櫃買規定都經獨立查核，但查核只看得到搜尋摘要。送件前要由推薦證券商與會計師逐字確認（附錄一最後列了 5 件一定要問的事）。

## 一句話結論

> **2031 上櫃做得到，前提是兩件事：2027-03-31 全體股東簽重組方案；2029–2030 年集團合併帳賺錢、而且沒有累積虧損。【定案】的倒推表有一處接不起來，要在 2026 年底前和會計師一起改。**
>
> 1. **接不起來的地方**：交接包寫「2028 第一個查核年度 → 2029 公開發行」。但一般公開發行要兩本經會計師查核的年報（涵蓋三個年度）🟡[IP-4]；到 2029 年，手上只有 2028 一本。二選一：
>    - **甲**：查核提前一年，從 2027 年度開始。2029 公開發行、2030 興櫃、2031 上櫃都照【定案】；最快可在 2030 年第 1 季掛牌，對 2031 年底約有 21–23 個月緩衝【估算，反向驗證】。代價是多一年查核費、2027 是重組年，而且多一個查不到依據的條件：2027 年才成立的上市主體，能不能用追溯重編的比較期補足一般公發要的「3 個年度」⚪[IL-6]。
>    - **乙**：查核起點不動，2030 年登錄興櫃時「併送簡易公開發行」（一本年報、兩個年度即可）✅[IP-3] ✅[IL-3]。最快可在 2031 年第 1 季掛牌，對 2031 年底約有 9–11 個月緩衝【估算，反向驗證】。
>    - **怎麼選**：2026-12-31 前問會計師與推薦證券商兩件事：2027 年度能不能查（含期初數）；新設主體能不能用追溯重編的比較期公發。兩件都「能」→ 甲；任一「不能」→ 乙，仍趕得上 2031。原本寫「乙完全沒有緩衝」，是在還沒查到審查天數時的判斷，反向驗證後更正。
> 2. **上櫃看的是集團帳**：最近一年稅前淨利 ≥400 萬台幣、決算無累積虧損，而且稅前淨利占股本最近一年 ≥4%（或兩年均 ≥3%、或兩年平均 ≥3% 且最近一年較好）✅[IP-1]。New Tech 併表的虧損只要讓集團出現累積虧損，三個比率選項都不能用。所以 New Tech 要不要併表、每年最多燒多少，2027 年重組時就要定。
> 3. **治理要提前兩年做**：興櫃前獨董 ≥2 席、設薪酬委員會；上櫃前獨董 ≥3 席且 ≥董事席次 1/3、審計委員會、董事會不得單一性別 ✅[IP-6]。內部控制要在送件前**整整 12 個月**都在運作，會計師才出得了專審報告（原本以為 6 個月，已被推翻）[IP-7]。
> 4. **控股結構先查清楚**：控股公司設在台灣，對大陸累計投資受「淨值或合併淨值 60%」上限，取得經濟部營運總部認定可豁免 ✅[IP-9]；設在境外（KY），昆山若是重要子公司，要臺籍董事過半等較嚴的條件 🟡[IP-8]。
> 5. **每一期要到位的錢**：New Tech 只做檢驗＋後段，到 2028 年底累計 0.70–1.15 億台幣；做整線是 0.90–1.66 億。之後每半年再 0.13–0.20 億維持團隊【估算】。如果真照交接包營收路徑賣出去，2031 年底光營運資金就要 8.8–13.2 億台幣，Pre-IPO 的規模要照這個定（第 1 節）。

## 4. New Tech 在上市路上的三個決定

上市的是集團，但 New Tech 的三個決定會直接影響上櫃條件。三個都要在 2027-03-31 的重組方案裡寫定。

**決定一：併表還是不併表**（財務長組第 7 條）

| | 併表（New Tech 在上市主體下） | 不併表（New Tech 在集團外） |
|---|---|---|
| 好處 | 可以當集團的成長故事；不必解釋關係人交易 | New Tech 的虧損不進集團帳 |
| 代價 | 虧損直接扣集團稅前淨利；只要出現累積虧損，三個比率選項都不能用 ✅[IP-1] | 本業向 New Tech 買設備、提供產線與人，全部是關係人交易，要逐筆說明價格公允；以後要注入上市主體，又是一筆關係人收購【推論】 |
| 要算的數【估算】 | 股本假設 3 億台幣、4% 是 1,200 萬：New Tech 只做檢驗＋後段時，第 2 年虧 2,744–4,472 萬，本業稅前要 ≥3,944–5,672 萬，本業營收（利潤率 3.9%）要 ≥10.1–14.5 億台幣；走整線時要 ≥14.6–26.1 億 | — |

- **放棄門檻**（財務長組）：擬制 2028 年合併稅前淨利 <股本的 4% → 三選一：整線延到上櫃後；New Tech 暫不併表並先訂好關係人交易政策；或上櫃目標後延。
- 2031 送件時，被檢查的是 2029、2030 兩年；但 New Tech 燒錢最兇的 2027Q4–2028Q3 會留在「累積虧損」裡。

**決定二：New Tech 股份怎麼換成上市主體的股份**（第 6 章投資人第 12 條）

- New Tech 獨立新設，退出卻要靠集團上市。外部投資人、技術長股權、技術合夥人 B 路徑（作價入股 10–20%）都要換股。
- 換股公式要在重組方案裡事先寫定，否則每一輪都要和家族重新協商，利益衝突明顯【推論】。
- 投資人紅隊的建議是：預設退出走「策略出售」（杰克、HCW、Texpa、AI 驗布商），集團上櫃只當加分【提案】。

**決定三：關係人交易怎麼訂價**（財務長組第 10 條、治理第 3 點）

- New Tech 使用昆山線時、檢驗員、機修，按成本加成付費給本業；本業向 New Tech 買設備，價格上限是同功能現成機的報價；每季揭露【提案】。
- 沒有訂價政策，上櫃審查時要逐筆解釋。

**New Tech 能不能當成長故事**

|---|---:|---|
